# 企业官网审美 Skill

把企业产品资料、核心卖点与应用场景，整理成清晰、有品牌感的官网产品页或展会落地页。

包含页面结构、视觉验收规范，以及可复用的工业机器人 HTML 模板。适合产品目录、官网首页和展会推广页面。

## 安装

把本仓库地址发给支持本地文件操作的 AI 助手，并告诉它「帮我安装这个 Skill」。安装时保留整个目录中的 SKILL.md、references 和 assets。

## 使用

> 用企业官网审美 Skill，根据我提供的品牌、产品参数、卖点和应用场景制作企业官网页面，交付可本地打开的 HTML。

## 方法来源

来自企业增长陪跑实践。通过确认产品资料、梳理客户选型信息和检查桌面与移动布局，把产品表达沉淀为可复用的企业内容资产。
