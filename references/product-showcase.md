# 产品展示页（机器人模板）

用于给「卖硬件产品」的公司做对外展示件：企业官网首页、产品目录页、新品发布页、展会落地页。模板资产为 `assets/robot-product-template.html`（单文件机器人企业官网，六轴机械臂 SVG 线稿主视觉，无外部图片依赖）。

## 一、默认信息结构（自上而下）

1. **首屏**：一句主张（≤9 字/行，两行内）+ 一段 40 字内说明 + 2 个行动按钮 + 主视觉 + 3 个参数标签。
2. **KPI 条**：3–4 个数字（交付台数、良率、节拍、行业数），带单位与口径说明。
3. **产品线**：3–4 个型号，每卡必须有「型号 / 一句话定位 / 3 个关键参数 / 典型工况」。没参数的产品卡等于占位符。
4. **技术能力表**：5–6 行，把"能做什么"写成可验收指标（重复定位精度、MTBF、防护等级、通信协议、标定方式、支持的调度规模）。
5. **行业方案**：4 个场景，每格写客户收益，不写公司荣誉。
6. **关于/资质**：深色段，放成立年份、产能、认证、交付案例数。荣誉墙放最后，不要放首屏。
7. **CTA**：一次评估邀约，写清"提交什么、多久回复"。
8. **页脚**：地址、电话、备案号、公众号/视频号入口。

## 二、产品优先的写法

- **参数前置**：先给量程/精度/节拍/负载，再讲价值。B 端买家先看能不能用。
- **每张产品卡都要能被单独截图发出去**：型号、关键参数、工况、图片/线稿齐全。
- **不用"赋能/生态/闭环/全栈"**，改成能验收的动词：替代 2 名搬运工、节拍 45 件/分钟、换型 3 分钟。
- **数字必须标口径**：3,200 台是"累计交付"还是"年产能"，写清楚，否则一眼假。
- **不要虚构认证**：CE / ISO / CR 认证没拿到就不写。

## 三、视觉与实现

- 配色与字号见 `visual-spec.md`：墨黑 + 米白 + 单一强调色（信号橙/工程蓝），禁紫蓝渐变。
- 主视觉优先用**矢量线稿**而不是产品渲染图：无素材依赖、可无限缩放、显专业。模板里的六轴机械臂即为此写。
- 分区用编号（01 产品 / 02 技术 / 03 行业 / 04 关于），替代彩色大色块。
- 单文件内联 CSS，字体用系统无衬线栈，不引外部字体。
- 动效只做三件事：入场淡入、数字滚动、线条描边。不做视差、不做鼠标跟随光斑。

## 四、套用到其他品类

模板的骨架与配色可直接换内容，机器人→其他硬件只需改四处：主张句、KPI 口径、产品参数维度、行业场景。参数维度示例：

| 品类 | 关键参数维度 |
|---|---|
| 工业机器人 | 负载、臂展、重复定位精度、防护等级、通信协议 |
| 称重设备 | 量程、分度值、台面尺寸、材质、仪表型号、是否含校准 |
| 检测设备 | 检测精度、节拍、误判率、被检尺寸范围、数据接口 |
