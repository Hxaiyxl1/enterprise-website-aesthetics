# 交付物视觉规范

适用于本技能产出的三类件：PPT、HTML 报告、词云页。目标是"看起来像人做的"，不是"看起来像 AI 生成的模板"。

## 一、色彩

- 主色深蓝 `#1B4A8B`，辅助灰 `#5B5F66`，分隔线 `#E3E1DA`，底 `#F5F4F0` / `#FFFFFF`。
- **橙色 `#E8743B` 只用于关键变化、待决策项、异常值**，不做装饰色，一页不超过 3 处。
- 禁用：紫蓝渐变、玻璃拟态、"科技感"光晕、随机彩色图标。这是最典型的 AI 模板特征。

## 二、字体与排版

- 中文无衬线：`PingFang SC / Microsoft YaHei / Source Han Sans`。
- 数字与型号可用等宽字体做标签，但不要整段等宽。
- 标题紧字距、大字号、短句；正文行高 1.5–1.7。
- 左对齐为主。**不做整段居中**，居中只用于封面标题与数字卡。
- 每屏一个主观点，留白靠外边距给，不靠缩小字号挤内容。

## 三、结构

- 分区用编号（01/02/03）或细分隔线，不用彩色大色块切屏。
- 表格优先于卡片墙。三线表 + 无竖线，表头浅灰底。
- 数据先于装饰：先想清楚要读者比较什么，再决定图还是表。

## 四、图表

- 写清单位、日期、样本范围。
- 同一张图只比较同口径数据；不可比的分开展示。
- 中国语境下涨用红、跌用绿，不要套用欧美配色。
- 少于 3 个观测点不画折线。

## 五、HTML 交付

- 单文件，内联 CSS，不引外部字体与 CDN，避免离线打开样式塌掉。
- 宽屏优先，`max-width` 控制在 1100–1200px；表格允许横向滚动，不要压缩字号。
- 正文 13–15px，表格 12.5–13px，标题 19–30px。
- 打印/截图友好：背景色用浅色，避免大面积纯黑反白。

## 六、截图验证流程（必须做）

交付前用无头浏览器实际看一眼，不要凭想象判断版式：

```bash
CHROME="/c/Program Files/Google/Chrome/Application/chrome.exe"
"$CHROME" --headless=new --disable-gpu --hide-scrollbars \
  --window-size=1440,900 --virtual-time-budget=2500 \
  --screenshot="C:/abs/path/shot.png" "file:///C:/abs/path/page.html"
```

要点：
- **截图路径必须用 Windows 绝对路径**，相对路径会报 `Failed to write file`（错误码 0x3）。
- `vh` 单位会导致页面高度随窗口变化，整页截图前在临时副本里固定 padding，再用 `document.title` 回传 `scrollHeight` 量出精确高度。
- 入场动画、计数器会让截图抓到中间态：临时副本里加 `.reveal{opacity:1!important;transform:none!important}`，并把 `data-count` 的 0 替换成终值。
- 临时副本用完即删，别污染交付目录。

## 七、验收清单

- 无文字重叠、无溢出边框、无被裁切。
- 卡片等高，栅格对齐。
- 表格行高一致，长文本已截断或换行。
- 图例、单位、日期齐全。
- 移动端断点至少不塌（单列即可）。
